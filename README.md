# **BroQiangStudio** 🚀

> **Welcome to my official personal portfolio repository!** This project is built from scratch to showcase my professional background, skills, and creative projects with a modern dark-mode design.

---

## **🌟 Key Features**

* **Multi-Language Support**: Seamlessly switch between **Traditional Chinese (繁體中文)**, **Simplified Chinese (简体中文)**, **English**, and **Bahasa Melayu**.
* **Responsive Multi-Page Layout**: Fully optimized for desktop, tablet, and mobile devices across different pages (`index.html`, `resume.html`, `portfolio.html`).
* **Modern Dark Theme**: Designed with a sleek, high-contrast dark aesthetic tailored for modern tech and creative portfolios.
* **Interactive Portfolio & Resume**: Clean UI components featuring project showcases with direct links and structured professional experiences.

---

## **🛠️ Tech Stack**

* **HTML5** - Structuring page content and semantics.
* **CSS3** - Custom styling, flexbox layouts, and dark-mode aesthetics.
* **JavaScript (Vanilla)** - Local state management and dynamic multi-language translation switching.
* **GitHub Pages** - Fast and reliable cloud hosting.
